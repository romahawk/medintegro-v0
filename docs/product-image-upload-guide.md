# Product Image Upload Guide

Save product images under `public/images/products/...` using the product slug folder that matches the route.

Recommended filenames for each product folder:

- `card.jpg`
- `hero-main.jpg`
- `hero-secondary-1.jpg`
- `hero-secondary-2.jpg`
- `deploy-1.jpg`
- `deploy-2.jpg`
- `deploy-3.jpg`

You can use `.webp` or `.png` instead when needed, but keep the same base filenames.
